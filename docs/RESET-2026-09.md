Two conclusions. The cheap open lanes did the work at one-tenth to one-eightieth of the paid

Caveat: one small task, one run each. This settles capability and cost order, not long-horizon
reliability. The open-models report lists the documented long-horizon failures per model.

## 2. What the reviewer research changes

- Our review prompts said "hunt for defects" and used a `DEFECT:` prefix. Framing research shows
  that inflates findings; the inverse ("be conservative") makes Opus 5 and Sonnet 5 silently
  drop real bugs; demanding a fix per finding made judges reject correct code three times as
  often. No study measures a fixed count directly, but a count is a documented manipulation
  lever in both directions.
- New rule set in `AGENTS.md` ("Reviewer prompts: no quotas, ever"): consequence threshold,
  explicit permission for an empty result, confidence and citation per item, find and filter as
  separate stages, whole review in the final message, swapped-order judging, no self-vendor
  judging, quorum is a gate not a proof.
- Conductor's verdict checklist (A2) is already the filter stage. The change is to the finding
  prompt in front of it, and to A3/A4 (judge hygiene) which the research now justifies with
  citations rather than instinct.

## 3. Pipeline shapes worth running, with what each would prove

Every shape below is a mission JSON conductor can already run, except where noted. Each is
listed with the receipt that decides it, so the next release is chosen by data.

**Shape A, cheap build then cross-vendor review then cheap fix.**
Build on Sonnet 5 (claude, write mode) or Gemini 3.7 Flash (antigravity), review cold on
Gemini 3.7 Flash and Grok 4.6 with the no-quota template and a verdict checklist, fix on the
builder's resumed session. Expected cost per release under $3 against $13 to $19. Receipt: the
same roadmap-sized task as v0.12.0 (C1-scale), gate pass rate and reviewer finding counts
versus the recorded Sol/Opus runs. (Rebased 2026-09-05: the original text named the shelved
OpenCode lanes as the builder.)

**Shape B, best-of-two cheap builds, one judge.**
Two cheap builders on the same spec in parallel; a Gemini judge scores both, both orders,
against the checklist; conductor keeps the winner (`require: any` plus judge verdict). Receipt:
how often the two builds disagree on the gate, and whether the judge picks the one that passed.
Needs B5 (early cancel and ranking) for the mechanical part; can be run by hand first.

**Shape C, Claude as reviewer only, cheap everything else.**
Opus 5 stays where the receipts say it earns its price (cold review found real defects both
times it was used), everything else moves to the cheap tier. Receipt: whether Opus finds
anything the Gemini and Grok reviewers missed on the same diff, over three missions.

**Shape D, local weights for read lanes.** Withdrawn 2026-09-04 with the shelving decision
below; the probe receipt (7 minutes per task, GPU flat out) is in `docs/archive/research-shelved/2026-09-04-live-probe-pi-local.md`.

Not a shape: Codex anywhere, until the operator lifts the pause.

## Decision 2026-09-06: D4 cloud offload is shelved

Operator decision after D3 shipped. `claude ultrareview`, `claude --cloud`, `codex cloud`, and
`cursor-agent worker` all work by sending the checkout or a snapshot of it to the vendor; this
repository is local-only by rule, so the item contradicts the rule it would have to break to be
probed. The receipts also say the laptop is not the bottleneck: reviews cost about a dollar and a
few minutes, and wall clock goes to Sonnet builds and the lead's merge and salvage time, which cloud
review does not touch. Not to be re-proposed for this repository. The one case that reopens it is a
different repository that already lives on a remote and wants review while the machine is off; the
probe then runs on a scratch repository on that remote.

## Decision 2026-09-04 (late): the open-model lanes are shelved

Operator decision after the pi + llama.cpp probe: OpenCode, OpenRouter, Ollama, pi, and local models
are shelved. Free hosted tiers fail the private-repo rule on data terms; paid OpenRouter saves nothing
over the existing cheap lanes; local inference is minutes per task with the GPU flat out, and a
smaller model would not be quieter (compute per token, not parameter count, drives the fans).
llama.cpp, the model file, and the pi provider config were removed from the machine. Everything in
`docs/research/2026-09-04-*` stays as the record.

The open-model and local-model receipts now live in [`docs/archive/research-shelved/`](archive/research-shelved/).
